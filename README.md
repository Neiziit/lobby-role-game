 🎭 PhasmoSuS

Un mini-jeu en ligne de rôles secrets, conçu en React. Crée un lobby, rejoins des amis, attribue des rôles mystérieux et tente de deviner qui est qui !

## 🚀 Fonctionnalités

- Création et rejoint de lobbys avec code unique
- Attribution aléatoire de rôles parmi une liste de 10
- Interface utilisateur simple et responsive
- Système de score et classement des joueurs
- Devine les rôles des autres joueurs pour gagner des points

## 🧪 Rôles disponibles

- Le Flambeau  
- L’Ombre  
- Rêveur  
- Le Sacrifié  
- Le Pestiféré  
- Le Faux-Messager  
- L’Éclaireur  
- La Sangsue  
- Le Superstitieux  
- Le Maudit  

## 🛠 Tech Stack

- React.js
- Tailwind CSS / shadcn/ui (pour les composants)
- Vite ou Create React App (au choix)

## 📦 Installation

```bash
git clone https://github.com/tonpseudo/lobby-role-game.git
cd lobby-role-game
npm install
npm start
```
